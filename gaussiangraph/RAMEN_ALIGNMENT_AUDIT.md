# ramen 方法与评估核对

范围只限 ramen。论文依据：https://arxiv.org/html/2503.04034v1 ，III-B、III-C、IV-A、Table I。

## 已确认与论文方向一致的部分

论文 IV-A 明确描述逐高斯与文本计算余弦相似度并取最高类别；Table I 要求在三维解码 LangSplat / LEGaussian 后渲染。当前统一评估符合这两个原则。旧的 top1 单簇选择与这一分类描述不同，不应当作为当前 Table I 的主结果。

现有 GT 使用 LangSplat 标注，ramen 7 视角、71 项。精确类别集合、层选择、alpha 阈值等作者未完整公开，当前 14 类竞争分类、alpha>.7 和 LangSplat 最大可见高斯余弦选层仍属独立设置，不能视为完整对齐。

## 已通过的实现检查

CF 6 项测试全部通过，覆盖量化前向值与直通梯度、在线中心逐点更新、FPFH 原始索引、梯度历史重映射、细分和单位空间细分。没有证据显示当前低分是直通梯度完全断开。

当前 CF 从固定 30000 步几何训练，不发生增密或删点，因此本次运行没有高斯数变化的索引重排。重映射有单元测试，但不能据此声称已在动态增密训练中完成端到端集成。

## 确认的主要损失来源

| 项目 | OpenGaussian | 独立 CF v2 | SAM2+confidence+CF |
| --- | ---: | ---: | ---: |
| 有点占用的簇数 | 198 | 4837 | 5263 |
| 簇大小中位数 | 2521 | 87 | 76 |
| 有非零 CLIP 特征的高斯比例 | 73.18% | 8.44% | 29.86% |
| 非零特征且匹配至少 5 视角的高斯比例 | 56.00% | 0.76% | 12.30% |

这证明 CF 簇显著细碎、关联覆盖率低；不能仅把低分解释为方法不如基线。CF 的 Follow 阶段日志中已增加到 2745 簇，细分又增加到 4837，因此问题并非只出在最后细分。

保持训练、关联、分类、渲染完全不变，仅将评估匹配视角门槛由 5 降到 1：

| 方法 | 原门槛 mIoU | 1 视角门槛 mIoU |
| --- | ---: | ---: |
| OpenGaussian | 20.48% | 19.91% |
| 独立 CF v2 | 6.46% | 16.25% |
| SAM2+confidence+CF | 7.70% | 8.68% |

这是诊断对照，不替换原始主结果。门槛造成 CF 明显额外损失，但单独放宽它无法解决 SAM2 版本的问题，也不能恢复没有 CLIP 关联的点。

数值证据：`/media/joe/Data/gaussiangraph/experiments/alignment_audit/coverage.json`、`feature_scales.json`、各 `*_occ1/metrics.json`。新参数 `--min-association-views` 默认仍为 5，所有对照均显式保存配置。

## 关联与训练仍存在的差异

1. 论文 III-C 以逐视角最大 IoU 建立语义对应，再跨视角平均。当前复用了 OpenGaussian 的额外伪特征方差筛选（>.006 删除）、alpha>.8、匹配得分>.2、最小簇大小等门槛；其中 CF v2 使用 IoU 与特征距离联合分数，SAM2 版本使用 IoU。这些额外条件和两版本间差异必须拆开验证。零背景 mask 已与零 CLIP 行对齐，未发现先前怀疑的索引整体偏移。
2. 渲染器对实例特征做逐点单位归一化；Control 和 Follow 却使用原始特征加 XYZ*.5，细分再改单位特征。原始特征模长不参与渲染语义，但参与距离，会使聚类受无关的模长差影响。这是明确的表征尺度不一致，影响大小仍需对照验证。
3. CF 阈值、XYZ 权重、控制点数、梯度中位数阈值、时序和细分支持数是独立实现的选择，论文没有足够参数保证逐项复刻。
4. 置信度定义采用 predicted_iou*stability；Eq.3 实现除以图像像素数，并乘 .01；论文写的是求和，未给这里相同的缩放。这影响与 Eq.4 的相对权重，不能称损失已逐项照搬。
5. LangSplat 使用共享 OpenGaussian 几何；LEGaussian 使用原生联合训练、量化 batch=4；二者均需保留设置差异。LE 的三维解码目前为 codebook argmax；仓库同时提供 softmax 选项，作者 Table I 未说明选项，后续可做固定条件敏感性检查。

本轮已完成代码核对、覆盖率量化和无需训练的视角门槛对照。尚未完成新的 CF 训练或证明其达到论文性能。

## 后续核查：SAM2 与 LEGaussian

全量检查了 SAM2 的 131 帧、3180 个掩码，掩码/置信度/CLIP 行数全部对应，无空标签掩码。覆盖处理后，390 个掩码保留面积不足原始的一半；平均像素未覆盖率 30.74%。当前 CLIP 从原始重叠掩码裁剪，而训练使用覆盖后的互斥区域，存在区域不一致。未覆盖像素包括背景，不能解释为目标漏检率；该结果不能独立证明低分原因。详见 `experiments/alignment_audit/sam2_mask_layout.json`（Data 盘）。建议下一轮固定模型与损失，对比与训练区域严格对应的 CLIP 裁剪，或支持原始重叠掩码的训练与关联。

LEGaussian 固定 checkpoint/codebook，仅改三维解码为 softmax 加权，mIoU 从 8.98% 到 10.47%，Acc@0.25 从 9.86% 到 12.68%，Acc@0.5 仍为 0%。因此 argmax 解码并非低分唯一原因。结果：`experiments/alignment_audit/legaussian_softmax/metrics.json`（Data 盘）。原生仓库支持两种方式，不能据更高分断言 softmax 就是论文设置。

已增加 CF `--cluster-space unit`（默认仍 raw），使 Control/Follow 可使用与渲染一致的单位实例特征，并暴露 `--position-scale`；尺度不变性与默认兼容性测试通过。恢复训练拒绝更换这两个参数，防止已有簇和新距离定义混用。尚未重训验证效果，不能将该代码变更记为指标提升。
