# ramen Control-Follow 独立实现与实验

本轮目标是推进 GaussianGraph III-B 的可运行实现，先保持已有 SAM/CLIP 输入，
验证 Control-Follow 与完整训练/关联/评估链路。不是 GaussianGraph 官方代码完整复现，
也不能将单次实验差异全部归因于聚类。

这些计数定位了输出消失环节，不能单独证明根本原因是 CLIP、几何还是聚类。

原候选合并条件允许跨粗簇合并。为给任意数量的 CF 簇提供统一协议，本轮预先
固定为每个查询选一个 CLIP 相似度最高的簇，其余过滤和阈值不变。
在该 `top1_fixed_v1` 协议下，原模型结果为 **39.44% / 15.49% / 20.13%**。
14 项显式空预测仍计 0，分母仍为 71；不是通过删除困难样本提高指标。
原基线 metrics.json 未改写。不能把本轮协议直接等同于作者未公开的 Table 1 实现。

## 实现文件

代码均位于 `baselines/OpenGaussian/`：

- `scene/control_follow.py`：梯度历史、控制点采样、BIRCH、在线 Follow、特征细分、STE 量化。
- `train_control_follow.py`：冻结重建几何，训练实例特征；保存优化器、梯度历史、簇标签和 RNG 状态，支持显式恢复。
- `associate_control_follow.py`：任意簇数的分批语言关联，每批最多 8 簇。
- `experiments/evaluate_top1.py`：baseline 与 CF 共用的评估程序。
- `experiments/run_control_follow.py`：训练→关联→评估，任一步失败即停止并记录状态。
- `scripts/test_control_follow.py`：5 项核心回归测试。

梯度量化使用 `features + (cluster_mean - features).detach()`，前向取簇均值，
反向按恒等映射传回连续实例特征。控制阶段非控制点暂不量化。
Follow 依次处理剩余点，每次分配后立即更新簇均值，超过阈值则创建新簇。

FPFH 下采样使用 voxel trace，在每个体素内选原始高斯代表，避免把下采样索引
误用于原高斯特征。控制点数不足 5000 时使用可用体素数。
训练开始于已完成增密的 30000 步；此后冻结几何、不增密、不剪枝，点序保持不变。
梯度历史提供显式索引 remap，量化遇到点数变化会报错，不能静默复用过期索引。

## 必须明确的独立实现选择

论文：<https://arxiv.org/html/2503.04034v1>，方法 III-B。

以下细节在论文/公开片段中不足以唯一确定，均为本次工程选择：

- 原模型 30000 步检查点作为起点；Control 从 40000、Follow 从 50000、细分从 68000 开始，最终 70000。
- 稳定性统计 Control 前 1000 次迭代的梯度范数均值；仅纳入至少被观察一次的点。
- 论文未提供 epsilon。默认用**训练梯度的中位数**确定 epsilon，实值写入 stability.json；可通过参数改为固定 epsilon。
- FPFH 使用公开代码片段的描述子分量和排序；不声称该分数严格等于边缘显著性。
- BIRCH 特征为原始 6D 实例特征 ×1 与 XYZ ×0.5。阈值取这两部分标准差均值的平均，或显式参数指定。
- Control 每 200 步重新 BIRCH；Follow 固定按原始索引顺序逐点更新一次，其后每步更新量化簇均值。
- 簇内细分采用仅实例特征的 BIRCH，阈值 0.2；论文没有给出具体细分算法和数值。
- 仍用 OpenGaussian 的平滑/分离损失及第三方 SAM ViT-H 特征，**尚未加入置信度加权和 SAM2_L**。
- 关联默认保持 baseline 的 IoU×特征距离联合评分，以减少同时改动因素；提供 `--association-score iou` 作为后续论文关联方式实验入口。
- 单簇文本选择、出现次数过滤、尺度过滤、KNN、alpha=0.7 统一固定；不根据测试 GT 调阈值。
- 连续特征阶段重新运行，视角随机顺序为固定种子 0，不能恢复原 baseline 当时未保存的 RNG 状态；严格归因还需同训练框架/多种子的对照。

## 70000 步结束后的异常检查

训练已结束，但 v1 不能报告有效的 CF 分割结果。诊断如下：

| 阶段 | 簇数 | 单点簇数 |
|---|---:|---:|
| Control 49999 | 232（仅控制点） | 36 |
| Follow 67999 | 2745（全部高斯） | 373 |
| Refined 70000 | 485512（全部高斯） | 400463 |

总高斯数为 714346。异常明确出现在特征细分阶段，非 Follow 直接产生。
细分采用固定 0.2 阈值作用于未归一化的实例特征；训练中原始特征尺度已变化，
该设置导致严重碎片化。因而需要重新核对特征距离定义和细分尺度，不能将本次
训练损失下降视为语义分割改善，也不能声称已经复现论文。
已主动停止预计需数十小时的关联进程，保留所有检查点。可从 67999 步恢复，
不需要重新运行重建、连续学习和 Control/Follow。详细统计见输出目录
`cluster_diagnostics.json`；下一轮配置须独立保存，不覆盖 v1。


## v2 细分修复与 SAM2 后续队列

v2 从 v1 的 67999 步恢复，仅补跑 68000–70000，最终 **4837 簇**。
细分改用单位长度的实例特征，候选子簇需至少 32 个点支持；不足支持的片段并入
最近的有效子簇，若不足两个有效子簇则保留父簇。此支持阈值是独立实现选择，
未根据评估 GT 调整，也不声称来自论文。原 Follow 的小簇仍保留，未人为凑对象数。

新回归测试验证幅值缩放不应拆开同方向特征，以及小碎片不会单独成为子簇。
关联增加碎片化诊断：超过合理计算规模或过半高斯成为单点簇时，报错停止，
不会靠截断簇数掩盖问题。

SAM2＋置信度的代码、实验选择和执行队列见 `SAM2_CONFIDENCE.md`。
旧 v1 保留为失败实验；v2 独立目录 `outputs/ramen_control_follow_v2`。


## v2 统一 top-1 评估结果

v2 已完成关联和评估：Acc@0.25=11.27%，Acc@0.5=1.41%，mIoU=5.49%；71 项中有 5 项空预测。相同协议下原基线为 39.44% / 15.49% / 20.13%。本次独立 CF 实现明显退化，细分碎片化修复并不等于分割质量提升，不能称为复现成功。SAM2＋置信度完整训练已由队列启动，指标尚未得到；其损失定义不同，不可直接与旧损失大小比较。
